# Oxlet — แอปมือถือ (เวอร์ชันทดลอง)

แอปทดลองบน iPhone/Android ผ่าน **Expo Go** (ฟรี · ไม่ต้องมี Mac · ไม่ต้องสมัคร Apple Developer)
ไว้ประเมินก่อนตัดสินใจว่าจะจ่ายค่าทำแอปจริงไหม

แถบด้านล่าง 3 แท็บ — **login แล้วเปิดมาที่แชทเลย**:
1. **แชท (Connect)** — รายชื่อ + ค้นหา · อ่าน/ตอบ · รับลูกค้าจากคิว (เซลล์/แอดมิน) · ตัวเลขบนแท็บ = ลูกค้ารอ
2. **สแกน QR** — เปิดข้อมูลรถ · เปลี่ยนสเตป · ถ่ายรูปแนบ · เช็คลิสต์ตรวจรถ (ทุกบทบาท)
3. **ฉัน** — บัญชีที่ใช้ · ออกจากระบบ

คนงาน (ช่าง/ฝ่ายทะเบียน) ไม่เห็นแท็บแชท — เปิดมาที่สแกนเลย

> ⚠️ **ต่อกับเซิร์ฟเวอร์จริง** — ข้อความที่ตอบไปถึงลูกค้าจริง · สเตปที่เปลี่ยนเป็นของจริง
> ทดสอบการตอบให้ใช้ **ลูกค้าจำลอง** (Connect → ตั้งค่า → "ทดสอบระบบด้วยบัญชีจำลอง") ·
> แอปถามยืนยันครั้งแรกก่อนตอบลูกค้าจริงในแต่ละแชท

## เปิดบน iPhone

1. ติดตั้งแอป **Expo Go** จาก App Store
2. คอมกับ iPhone ต่อ **Wi-Fi วงเดียวกัน** (ห้ามใช้ `--tunnel` — เว็บไม่ยอมส่งรหัส login ไปที่อยู่ภายนอก)
3. บนคอม:
   ```powershell
   cd mobile
   npm install        # ครั้งแรกเท่านั้น
   npx expo start
   ```
4. เปิดกล้อง iPhone สแกน QR ที่ขึ้นในหน้าจอคอม → เปิดใน Expo Go
5. ถ้าโทรศัพท์ต่อไม่ติด: Windows Firewall ต้องอนุญาต Node.js (พอร์ต 8081) ในเครือข่ายส่วนตัว

## เข้าสู่ระบบ

- **เซลล์/แอดมิน** → "เข้าสู่ระบบด้วย LINE" (LINE Login ตัวเดียวกับเว็บ)
- **ช่าง/ฝ่ายทะเบียน/ล้างรถ** → "ชื่อผู้ใช้ + รหัส" → ในหน้าเว็บกด **"▸ เข้าสู่ระบบแอดมินระบบ"** แล้วกรอกบัญชีที่ใช้กับ /track/
- ถ้ากด LINE แล้วเด้งไปแอป LINE แล้วไม่กลับมา: เปิด Safari เข้าเว็บ Oxlet แล้ว login ให้เรียบร้อยก่อน
  แล้วค่อยกดในแอปใหม่ — แอปจะข้าม LINE ไปเลย (ใช้คุกกี้ของ Safari ร่วมกัน)
- token อายุ 30 วัน · พนักงานที่ถูกปิดใช้งาน/ปิดบัญชีที่ /track/users/ จะใช้แอปไม่ได้ทันที

## ทำงานยังไง (ฝั่งเว็บ)

แอป **ไม่มี API ชุดใหม่** — เรียก API เดิมของเว็บทั้งหมด ด้วย `Authorization: Bearer <token>`
(`dashboard/middleware.py` แปลง token เป็น "คนที่ login อยู่") · สิทธิ์ทุกอย่างเช็คที่เซิร์ฟเวอร์เหมือนเว็บ

| ใช้ทำอะไร | API |
|---|---|
| login | `/m/login` → LINE / หน้า login → `/m/handoff/<pid>` → `POST /api/m/token` (PKCE) |
| แชท | `/connect/api/summary` · `inbox` · `chat` · `claim` · `reply` |
| รถ | `/track/api/m/car/<code>` · `POST /track/api/upload` · `POST /track/api/seller_set_stage` |

## ไม่มีในเวอร์ชันทดลอง

- **แจ้งเตือน (push)** — ต้องเป็นแอปที่ build เอง (ต้องมีบัญชี Apple Developer $99/ปี สำหรับ iPhone)
- ส่งรูปหาลูกค้าในแชท · จ่ายเบอร์ · ข้อมูลลีด · ตั้งความด่วน/ธงงานค้าง (ใช้หน้าเว็บ)

  `python record_tutorial.py all` → `videos/oxlet-seller.mp4` · `videos/oxlet-admin.mp4` + เวลาของแต่ละขั้น (`*.steps.json`)
- `build_guide.py` + `guide_template.html` — หน้าคู่มือ (วิดีโอ + ขั้นตอนที่แตะแล้วข้ามไปตรงนั้น) · เผยแพร่ที่ https://claude.ai/artifact/9Rrspbmts7eZV1GGsKHoec
- ไฟล์ mp4 ไม่เข้า git (ใหญ่ · อัดใหม่ได้) · แก้ต้นแบบแล้วต้องอัดใหม่ เพราะวิดีโอกดตามตำแหน่งปุ่มจริง
- **เสียงพากย์** — `narration.py` (บทพากย์ ลำดับ = ปกเปิด + ทุกขั้น + ปกปิด) · `tts.py` สร้างเสียงด้วย Gemini TTS (`gemini-3.8-flash-tts` · เสียง `Sulafat` · ใช้ GEMINI_API_KEY เดิม) เก็บใน `voice_cache/` รันซ้ำไม่เสียเงินซ้ำ · ตัวอัดรอให้แต่ละบรรทัดพูดจบก่อนขึ้นขั้นถัดไป แล้ววางเสียงตามเวลาขั้น · ปิดเสียงด้วย `OXLET_NO_VOICE=1` · เปลี่ยนเสียงด้วย `OXLET_TTS_VOICE` (เสียงผู้ชาย = แก้บทให้ลงท้าย ครับ ด้วย)
