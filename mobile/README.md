# Oxlet — แอปมือถือ (เวอร์ชันทดลอง)

แอปทดลองบน iPhone/Android ผ่าน **Expo Go** (ฟรี · ไม่ต้องมี Mac · ไม่ต้องสมัคร Apple Developer)
ไว้ประเมินก่อนตัดสินใจว่าจะจ่ายค่าทำแอปจริงไหม

แถบด้านล่างจัดตามบทบาท — **ข้อมูลจริงทั้งหมด** (ไม่มีข้อมูลสมมติแบบต้นแบบแล้ว) · login แล้วเปิดมาที่แชท:

| บทบาท | แท็บ |
|---|---|
| เซลล์ | แชท · **วันนี้** · รถ · ฉัน |
| แอดมิน / ผู้บริหาร | แชท · **ภาพรวม** · **ห้องพัก** · รถ · ฉัน |
| คนงาน (ช่าง/ฝ่ายทะเบียน/ล้างรถ) | **งานวันนี้** · รถ · ฉัน |
| จัดซื้อ | **วันนี้** · รถ · ฉัน |

- **แชท (Connect)** — รายชื่อ + ค้นหา · อ่าน/ตอบ · รับลูกค้าจากคิว · ตัวเลขบนแท็บ = ลูกค้ารอ
- **วันนี้** — เซลล์: เช็คชื่อ · ยอดเดือนนี้ + คะแนน · ลูกค้ารอตอบ · ใบจ่ายลีด (เหลือกี่นาที) · ตามด่วน (ลำดับเดียวกับข้อความ LINE ทุกเช้า) · ดีลค้าง · รถตรงลูกค้า ·
  แอดมิน: ยอดวันนี้ · ลูกค้ารอรับ/รอจ่ายเบอร์ · เช็คชื่อทั้งบริษัท · รถค้าง · คนงาน: สแกน QR · คิวรถของทีม · จัดซื้อ: เคสที่ต้องโทร · รุ่นที่ขาดตลาด
- **ห้องพัก** (แอดมิน) — ลีดรอจ่ายเบอร์ทุกช่องทาง · กดชื่อเซลล์ = จ่ายเบอร์ (ถามยืนยันก่อนส่งใบเข้ากลุ่มจ่ายเบอร์จริงทุกครั้ง)
- **รถ** — สแกน QR · ค้นหาทะเบียน · กรองพร้อมขาย/ค้างนาน/ออกนอกลาน · แตะรถ = เปลี่ยนสเตป · **เบิก-คืนรถ**
- **ฉัน** — เช็คชื่อวันนี้ · คะแนนแยก 6 ด้าน (เซลล์) · ออกจากระบบ

> ⚠️ **ต่อกับเซิร์ฟเวอร์จริง** — ข้อความที่ตอบไปถึงลูกค้าจริง · สเตปที่เปลี่ยน/การเบิก-คืนรถเป็นของจริง ·
> จ่ายเบอร์จากแท็บห้องพัก = ใบเข้ากลุ่มจ่ายเบอร์จริง
> ทดสอบการตอบให้ใช้ **ลูกค้าจำลอง** (Connect → ตั้งค่า → "ทดสอบระบบด้วยบัญชีจำลอง") ·
> แอปถามยืนยันครั้งแรกก่อนตอบลูกค้าจริงในแต่ละแชท

## เปิดบน iPhone

1. ติดตั้งแอป **Expo Go** จาก App Store
2. คอมกับ iPhone ต่อ **Wi-Fi วงเดียวกัน** (ห้ามใช้ `--tunnel` — เว็บไม่ยอมส่งรหัส login ไปที่อยู่ภายนอก)
3. **ล็อกอินบัญชี Expo บัญชีเดียวกันทั้ง 2 ฝั่ง** (Expo Go บน iPhone บังคับตั้งแต่ SDK 57 · Android ยังไม่บังคับ)
   - ใน Expo Go: แตะรูปคนมุมขวาบน → ใส่ชื่อผู้ใช้ + รหัสผ่าน (**ไม่มีปุ่ม Google** — บัญชีที่สมัครด้วย Google ใช้ไม่ได้ ต้องเป็นบัญชีที่มีรหัสผ่าน)
   - บนคอม: `npx expo login` แล้วเช็คด้วย `npx expo whoami` ว่าเป็นบัญชีเดียวกัน
4. บนคอม:
   ```powershell
   cd mobile
   npm install        # ครั้งแรกเท่านั้น
   npx expo start
   ```
5. เปิดกล้อง iPhone สแกน QR ที่ขึ้นในหน้าจอคอม → เปิดใน Expo Go
6. ถ้าโทรศัพท์ต่อไม่ติด: Windows Firewall ต้องอนุญาต Node.js (พอร์ต 8081) ในเครือข่ายส่วนตัว

## เข้าสู่ระบบ

- **เซลล์/แอดมิน** → "เข้าสู่ระบบด้วย LINE" (LINE Login ตัวเดียวกับเว็บ)
- **ช่าง/ฝ่ายทะเบียน/ล้างรถ** → "ชื่อผู้ใช้ + รหัส" → ในหน้าเว็บกด **"▸ เข้าสู่ระบบแอดมินระบบ"** แล้วกรอกบัญชีที่ใช้กับ /track/
- ถ้ากด LINE แล้วเด้งไปแอป LINE แล้วไม่กลับมา: เปิด Safari เข้าเว็บ Oxlet แล้ว login ให้เรียบร้อยก่อน
  แล้วค่อยกดในแอปใหม่ — แอปจะข้าม LINE ไปเลย (ใช้คุกกี้ของ Safari ร่วมกัน)
- token อายุ 30 วัน · พนักงานที่ถูกปิดใช้งาน/ปิดบัญชีที่ /track/users/ จะใช้แอปไม่ได้ทันที

## ทำงานยังไง (ฝั่งเว็บ)

แอป **ไม่มี API ชุดใหม่** — เรียก API เดิมของเว็บทั้งหมด ด้วย `Authorization: Bearer <token>`
(`dashboard/middleware.py` แปลง token เป็น "คนที่ login อยู่") · สิทธิ์ทุกอย่างเช็คที่เซิร์ฟเวอร์เหมือนเว็บ

| ใช้ทำอะไร | API |
|---|---|
| login | `/m/login` → LINE / หน้า login → `/m/handoff/<pid>` → `POST /api/m/token` (PKCE) |
| แชท | `/connect/api/summary` · `inbox` · `chat` · `claim` · `reply` |
| วันนี้ / ฉัน | `/api/m/home?lazy=1` + `/api/m/home?part=follow` (ตามด่วนโหลดแยก ไม่ให้หน้าแรกรอ) |
| ห้องพัก | `/connect/api/inbox?view=tocode` · `POST assign_lead` · `POST park_assign` |
| รถ | `/track/api/cars` · `/track/api/m/car/<code>` · `POST /track/api/upload` · `POST /track/api/seller_set_stage` · `POST /track/api/set_priority` · `POST /track/api/set_flags` |
| สถานะลูกค้า (ตามด่วน) | `POST /crm/api/lead_status` |
| วิดีโอ/ไฟล์ในแชท | `/connect/api/media` (โหลดลงเครื่องพร้อม token แล้วเล่น/เปิด) |
| เบิก-คืนรถ | `POST /checkout/api/car_out` · `POST /checkout/api/car_return` |

## ไม่มีในเวอร์ชันทดลอง

- **แจ้งเตือน (push)** — ต้องเป็นแอปที่ build เอง (ต้องมีบัญชี Apple Developer $99/ปี สำหรับ iPhone)
- ส่งรูปหาลูกค้าในแชท · Run Auto / ตั้งเลขเอง / ไม้ 2 ในห้องพัก (ใช้หน้าเว็บ)
- เช็คชื่อด้วยเซลฟี่ในแอป — ยังเช็คชื่อด้วยรูปในกลุ่ม LINE ตามเดิม (แอปแค่โชว์ผล)
