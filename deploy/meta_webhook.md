# เปิดรับแชท Facebook แบบ "Facebook ส่งมาเอง" (Messenger webhook)

เดิมระบบ **ถาม Facebook ทุก 1 นาที** ว่ามีแชทใหม่ไหม → กินโควต้า API และเสี่ยงโดนพัก token
ตอนนี้เปลี่ยนเป็น **Facebook ส่งแชทมาหาเราเองทันทีที่ลูกค้าพิมพ์** (ไม่ใช้โควต้าเลย)
และเก็บการถามเป็น **ทางสำรองทุก 10 นาที** (ตั้งได้ 2–60 นาที) เผื่อ Facebook ส่งพลาด

> ระหว่างที่ยังไม่ได้ทำตามขั้นตอนข้างล่าง ระบบใช้ทางสำรองอย่างเดียว = แชท Facebook เข้า Connect ช้าสุด 10 นาที

---

## ขั้นที่ 1 — ตั้งคำลับ 2 ตัวในเซิร์ฟเวอร์

เปิด `/opt/oxlet/.env` แล้วเพิ่ม 2 บรรทัด (ค้นก่อนว่ามีอยู่แล้วหรือยัง — ถ้ามี 2 บรรทัดซ้ำ ตัวล่างจะทับตัวบน):

```
META_APP_SECRET=<App Secret ของแอป>
META_WEBHOOK_VERIFY_TOKEN=<คำลับที่ตั้งเอง>
```

| ค่า | เอามาจากไหน |
|---|---|
| `META_APP_SECRET` | developers.facebook.com → แอปของเรา → **App settings → Basic → App Secret** (กด Show) |
| `META_WEBHOOK_VERIFY_TOKEN` | **ตั้งเองได้เลย** ตัวอักษรมั่วๆ ยาวๆ เช่น `oxlet-fb-7Kq2…` · ใช้แค่ตอนลงทะเบียนในขั้นที่ 2 |

แล้วรีสตาร์ท:

```bash
sudo systemctl restart oxlet
```

> ★ **ไม่ตั้ง App Secret = ระบบไม่รับแชทจาก webhook เลย (ตอบ 503)** — ตั้งใจให้เป็นแบบนี้
> เพราะแชทที่เข้ามาจะกลายเป็นลูกค้าในคิวของเซลล์ทันที ถ้าไม่ตรวจลายเซ็น ใครรู้ URL ก็ยิงแชทปลอมเข้ามาได้

---

## ขั้นที่ 2 — ลงทะเบียน URL ในหน้าแอป Meta

developers.facebook.com → แอปของเรา → **Webhooks** (หรือ **Messenger → Settings → Webhooks**)

1. เลือก **Page**
2. **Callback URL** = `https://srv1793506.hstgr.cloud/api/meta/webhook`
3. **Verify token** = ค่าเดียวกับ `META_WEBHOOK_VERIFY_TOKEN` ในขั้นที่ 1
4. กด **Verify and save** — ผ่าน = Meta ทักทายระบบเราแล้วได้คำตอบถูก
5. ติ๊กช่องที่จะรับ: **`messages`** และ **`message_echoes`**

| ช่อง | ใช้ทำอะไร |
|---|---|
| `messages` | ลูกค้าพิมพ์เข้ามา → เข้าคิว Connect ทันที + เริ่มนับ 5 นาที |
| `message_echoes` | ทีมตอบในแอป Facebook / Business Suite → **หยุดนาฬิกาให้** (ไม่งั้นขึ้น "เลยเวลา" ทั้งที่ตอบแล้ว) |

> Verify ไม่ผ่าน → เช็คว่ารีสตาร์ทหลังแก้ `.env` แล้ว และพิมพ์ verify token ตรงกันทุกตัว

---

## ขั้นที่ 3 — ผูกเพจกับแอป (กดในหน้าเว็บ)

Connect → **ตั้งค่า** → การ์ด **Facebook Messenger**

1. กด **"ผูกเพจกับแอป (รับแชทผ่าน webhook)"** → ควรขึ้น "ผูกแล้วทุกเพจ"
2. กด **"ตรวจว่าเพจผูกแล้วหรือยัง"** → ทั้ง 2 เพจต้องขึ้น **ผูกแล้ว (message_echoes, messages)**

การ์ดเดียวกันบอกสถานะตลอด: Callback URL · Verify token ตั้งแล้วไหม · App Secret ตั้งแล้วไหม ·
**Facebook ส่งมาล่าสุดเมื่อไหร่** (หรือส่งมาแต่ไม่รับเพราะอะไร)

---

## ขั้นที่ 4 — ทดสอบ

ใช้บัญชี Facebook ของเจ้าของ ทักเพจ 1 ข้อความ → ภายในไม่กี่วินาทีต้องโผล่ใน Connect
และการ์ดตั้งค่าขึ้น "ส่งมาล่าสุด เมื่อสักครู่ · ข้อความใหม่ 1"

**ถ้าไม่โผล่:**

| อาการบนการ์ด | สาเหตุ / ทางแก้ |
|---|---|
| "Facebook ยังไม่เคยส่งมา" | ยังไม่ผ่านขั้นที่ 2 หรือ 3 · หรือ **แอปยังอยู่โหมด Development** (ดูข้อถัดไป) |
| "ไม่รับ: ลายเซ็นไม่ตรง" | `META_APP_SECRET` ไม่ตรงกับแอปที่ลงทะเบียน URL |
| "ไม่รับ: ยังไม่ได้ตั้ง META_APP_SECRET" | ยังไม่ได้ทำขั้นที่ 1 / ลืมรีสตาร์ท |

### ⚠️ ลูกค้าจริงต้องผ่าน App Review ก่อน — ไม่ใช่แค่กด Live

เอกสาร Messenger webhook ของ Meta เขียนไว้ตรงๆ:
- **Standard Access** = รับได้เฉพาะคนที่มีบทบาทในแอป (admin / developer / tester)
- **Advanced Access** = รับจากลูกค้า (คนที่ไม่มีบทบาทในแอป) — **ต้องผ่าน App Review**
  และการขอ Advanced Access ทุกตัว **ต้องยืนยันธุรกิจ (Business Verification)** ก่อน

ขั้นตอนเต็มคือ ยืนยันธุรกิจ → ส่ง App Review ขอ `pages_messaging` (Advanced Access) → อนุมัติแล้วเปลี่ยนแอปเป็น **Live**

**ระหว่างยังไม่ผ่าน:** ทดสอบด้วยบัญชีของเจ้าของ (มีบทบาทในแอป) ได้ครบ · **แชทลูกค้าจริงเข้าทางสำรองอย่างเดียว**
→ ตั้งทางสำรองให้ถี่พอ (2–5 นาที) ไม่งั้นแชทลูกค้าเข้า Connect ช้า แล้วขึ้น "เลยเวลา" ทันทีที่มาถึง
(เส้นตาย 5 นาทีนับจากเวลาที่ลูกค้าส่ง ไม่ใช่เวลาที่ระบบเห็น)
· ทางสำรองมีด่านหยุดเองเมื่อโควต้า API ใกล้เต็มอยู่แล้ว (อ่านจาก header ของ Meta)

**ตอบลูกค้าจาก Connect ก็น่าจะติดข้อเดียวกัน** — Standard Access ส่งข้อความได้เฉพาะคนที่มีบทบาทในแอป
ตอนนี้โหมดตอบเป็น "ทดสอบ" (ตอบได้เฉพาะแชทของเจ้าของ) อยู่แล้ว จึงยังไม่กระทบ

---

## ทางสำรอง (ถามเองเป็นรอบ)

Connect → ตั้งค่า → การ์ด Facebook Messenger → **"ทางสำรอง — ดึงจาก API"** เลือก 2 / 5 / 10 / 15 / 30 / 60 นาที

- webhook ทำงานแล้ว ตั้ง **30–60 นาที** ได้เลย (มีไว้กันพลาดอย่างเดียว)
- ระบบจำเวลาดึงล่าสุดไว้ร่วมกันทุก worker → ตั้ง 10 นาทีก็ดึงจริงทุก 10 นาที ไม่ใช่คูณจำนวน worker
- ลูกค้าใหม่ที่ webhook หาห้องสนทนาไม่เจอ → ข้อความเก็บไว้ในห้องชั่วคราวก่อน รอบสำรองเจอห้องจริงเมื่อไหร่ ย้ายเข้าห้องจริงให้เอง (ไม่หาย)
