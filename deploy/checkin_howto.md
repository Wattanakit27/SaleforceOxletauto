# เช็คชื่อเข้างาน — คู่มือสั้น

ระบบส่งเอง 2 รอบต่อวัน (แทน workflow ใน n8n): **รูปตาราง** แล้ว **ตามคนที่ยังไม่เช็คชื่อ**

---

## 1. ตั้งค่าที่หน้าไหน

| เรื่อง | ไปที่ | ตั้งอะไร |
|---|---|---|
| **รายชื่อ / เวลาเข้างาน / วันหยุด** | `https://<โดเมน>/dashboard/?panel=employees`<br>(เมนู ☰ → ทีม & สิทธิ์ → พนักงาน) | ชื่อเล่น · ตำแหน่ง/ทีม · เวลาเข้างาน · วันหยุด · หมายเหตุ |
| **ใครไม่ต้องเช็คชื่อ** (ผู้บริหาร) | หน้าเดียวกัน | ติ๊กช่อง **"เช็คชื่อ"** ออก → หายจากตารางทั้งหมด |
| **ใครถูกแท็กตอนมีคนไม่มา** | หน้าเดียวกัน | ติ๊กช่อง **"แจ้งเตือน"** |
| **ดูผลรายวัน / สรุปเดือน** | `https://<โดเมน>/dashboard/?panel=checkin`<br>(เมนู ☰ → ตรวจสอบ & Log → เช็คชื่อเข้างาน) | ดูอย่างเดียว |
| **ตรวจย้อนหลังว่าส่งออกจริงไหม** | `https://<โดเมน>/dashboard/?panel=sql` | `SELECT at, name, ok, detail FROM dash_event_log WHERE kind='line_send' ORDER BY at DESC` |

> **เวลาส่ง / กลุ่มปลายทาง / วันหยุดบริษัท** ยังตั้งผ่าน SSH (ดูข้อ 4) — ยังไม่มีหน้าเว็บ

---

## 2. ไม่อยากให้แท็ก ต้องพิมพ์ยังไง

**พิมพ์อะไรก็ได้ลงช่อง "หมายเหตุ" ของคนนั้น = ไม่โดนแท็ก** (กติกาเดียวกับของเดิม)

| สถานการณ์ | พิมพ์ในช่องหมายเหตุ |
|---|---|
| ลาป่วย / ลากิจ | `ลาป่วย` |
| ไปธุระก่อนเข้า | `ไปธุระก่อนเข้า 10 โมง` |
| ทดเวลา | `ทดเวลา` |
| ลาคลอด (ยาวหลายเดือน) | `ลาคลอด` |

- **ไม่จำกัดคำ** — ขอแค่มีตัวหนังสือในช่องนั้น ระบบก็ข้ามให้
- **ยังโชว์ในตาราง** (ตัวอักษรสีน้ำเงิน) แค่ไม่โดนแท็ก
- **หมายเหตุไม่หายเอง** — อยู่จนกว่าจะลบทิ้ง เหมาะกับลายาว (ลาคลอด/ลาบวช)
  · กลับมาทำงานแล้ว **ต้องลบออกเอง** ไม่งั้นจะไม่โดนตามตลอดไป
- ข้อความของระบบ (เช่น `ไม่พบข้อมูลรูป`) **ไม่นับ** เป็นหมายเหตุ

**วันหยุดประจำสัปดาห์** ให้ใส่ที่ช่อง "วันหยุด" แทน — ใส่หลายวันในช่องเดียวได้
เช่น `ศุกร์ เสาร์ อาทิตย์` (พิมพ์ชื่อวันเต็ม)

## 3. วันหยุดยาว / เทศกาล — ไม่ต้องไปพิมพ์ทีละคน

มี 2 ชั้นกันไว้แล้ว

**ชั้นที่ 1 — ตั้งวันหยุดบริษัท (ดีที่สุด)** วันนั้นจะไม่ส่งทั้งรูปและข้อความตาม
```bash
cd /opt/oxlet && .venv/bin/python manage.py checkin_schedule \
  --holiday 2026-12-31,2027-01-01,2027-01-02
```
ล้างทิ้ง: `--holiday none`

**ชั้นที่ 2 — กันแท็กหมู่อัตโนมัติ (มีอยู่แล้ว ไม่ต้องตั้ง)**
ถ้าวันไหน **ขาดเกิน 20 คน** ระบบจะ **ไม่แท็กรายคน** เปลี่ยนเป็นบอกจำนวนแทน
แต่ **ยังแท็กผู้บริหาร** เพราะขาดทั้งบริษัทคือเรื่องที่หัวหน้าต้องรู้ยิ่งกว่าเดิม

```
⚠️ แจ้งเตือนรอบ 10:00 น.
พนักงาน 43 คน ยังไม่เช็คชื่อ:
(เกิน 20 คน จึงไม่แท็กรายคน — ดูรายชื่อในรูปตาราง)

ยังไม่เช็คครับ
@ผู้บริหาร
```

ปรับเพดาน / ปิดการกัน:
```bash
.venv/bin/python manage.py checkin_schedule --max-tag 25   # เปลี่ยนเพดาน
.venv/bin/python manage.py checkin_schedule --max-tag 0    # ไม่กันเลย
```

> **ทำไมต้องมีชั้นที่ 2**: วันที่ระบบเช็คชื่อมีปัญหา (รูปไม่เข้า/n8n ล่ม) จะขาดทั้งบริษัท
> ถ้าแท็ก 43 คนทุกเช้า คนจะเริ่มปิดแจ้งเตือนกลุ่ม แล้วทีหลังเตือนอะไรก็ไม่มีใครเห็น

## 4. ตั้งเวลา / เปิด-ปิด (SSH)

```bash
cd /opt/oxlet

# ดูค่าปัจจุบัน + ดูว่าตอนนี้จะแท็กใครบ้าง
.venv/bin/python manage.py checkin_schedule

# ตั้งกลุ่ม + เวลา แล้วเปิด
.venv/bin/python manage.py checkin_schedule \
  --group C<ไอดีกลุ่มฝั่งบอทใหม่> --mode group \
  --table-time 09:30 --escalate-time 10:00 --on

.venv/bin/python manage.py checkin_schedule --off      # ปิด
```

**ทดสอบโดยไม่ยุ่งกับกลุ่ม**
```bash
.venv/bin/python manage.py checkin_report --dry-run              # ดูสรุป
.venv/bin/python manage.py checkin_report --escalate --dry-run   # ดูข้อความรอบสอง + จะแท็กได้กี่คน
.venv/bin/python manage.py checkin_report --to <ชื่อเล่น>         # ส่งรูปเข้าแชทส่วนตัว
```

## 5. ข้อควรรู้

- **แท็กได้เฉพาะในกลุ่ม** — ส่งเข้าแชทส่วนตัว LINE แท็กไม่ได้ ระบบจะเปลี่ยนเป็นรายชื่อให้
- **ไอดีต้องเป็นของบอทที่ส่ง** — คนที่ยังไม่เคยพิมพ์ผ่านบอทตัวที่ใช้ส่ง จะพิมพ์ชื่อแทนการแท็ก
  (เช็คจำนวนได้จาก `--escalate --dry-run`)
- **คนใหม่เข้ากลุ่มแล้วพิมพ์ = ระบบเพิ่มชื่อให้เอง** เหลือแค่มาเติมตำแหน่ง/เวลาเข้างาน/วันหยุด
- **ทุกการส่งถูกบันทึกใน `dash_event_log`** ตรวจย้อนหลังได้ว่าวันไหนส่งออก/ล้มเพราะอะไร
